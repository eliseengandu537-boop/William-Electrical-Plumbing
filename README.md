# William-Electrical-Plumbing

Responsive HTML demo website for William Electrical & Plumbing in Randburg.

Open `index.html` in a browser to preview the website. Includes scroll-linked text animations, WhatsApp enquiries and a demo service assistant with automated replies.

Built with HTML, CSS and JavaScript, with no build step or production dependencies. Photography is served locally; Google Fonts requires an internet connection and has system-font fallbacks. The assistant does not connect to a live AI service.

## Design and features

An editorial trades identity with ivory, charcoal and copper, a custom vector wordmark, local service photography, responsive navigation, FAQs, and a WhatsApp quote form. The form includes the customer’s suburb and leaves sending to the customer. All directional arrows are SVGs for consistent mobile rendering. Scroll motion respects reduced-motion preferences.
