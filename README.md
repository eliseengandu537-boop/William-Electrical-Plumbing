# William-Electrical-Plumbing

Responsive HTML demo website for William Electrical & Plumbing in Randburg.

Open `index.html` in a browser to preview the website. Includes scroll-linked text animations, WhatsApp enquiries and a demo service assistant with automated replies.

Built with HTML, CSS and JavaScript. Google Fonts and demo photography require an internet connection. The assistant does not connect to a live AI service.
